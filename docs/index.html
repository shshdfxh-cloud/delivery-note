不只检查“交了什么”。

审查对象是交付成果，不限于网页。先拆解客户目的，再核对文件、事实与实际效果；当前已接入文本、数据文件和静态网页检查。

03把目的变成可验收条件

查看 / 编辑精确验收规则

编辑后点击“应用规则”。没有可执行检查的条件会保留为“未验证”，不会被AI自动判为通过。

可选AI规划与解读 · 数据发送说明

AI规划会向SERV发送目的、文件名、文件角色、CSV列名和HTML控件标识；AI解读会发送当前报告中的派生事实。供应商组织设置可能允许数据收集。不要发送隐私或保密材料。离线审查不需要同意。

任何必需项失败 → 需要修改；缺少证据 → 不能证实；不会用平均分掩盖关键问题。
